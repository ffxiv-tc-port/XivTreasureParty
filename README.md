# XIV 寶物地圖工具小幫手

cycleapple 製作的寶物地圖協作插件的台服艦隊版本。與網頁版 [xiv-tc-treasure-finder](https://cycleapple.github.io/xiv-tc-treasure-finder/) 共用同一個同步後端，**遊戲內與網頁使用者可混合組隊**，即時同步同一份寶物地圖清單。

## 功能

- 建立／加入隊伍（8 碼代碼），即時同步成員狀態、寶物地圖清單、過期時間
- **只有建立或加入隊伍時才連線**：載入插件不會連到同步伺服器，離開隊伍後就不再連線；「啟動時自動重新加入上次的隊伍」預設關閉，可在隊伍面板切換
- **看得見的連線狀態**：隊伍面板顯示連線中／重連中／已斷線，斷線會自動重連，也可以按「重新連線」立刻重試
- 手動新增寶物地圖（等級 → 地圖 → 字母編號位置）
- **打開寶物地圖時自動選取** — 讀取剛解碼的那張圖，自動預選下方欄位（仍需按「加入清單」才會推送到隊伍）；可另外開啟「開圖後自動開啟地圖並設定旗標」（預設關閉）
- **地圖按鈕** — 直接在遊戲內開啟地圖並將旗標設在寶物點
- **前往按鈕** — 清單每列的「前往」與上方的「依路線前往下一個」，交給 Lifestream 帶路（勾「允許飛行」時 Lifestream 可用飛行坐騎跑最後一段）
- **發送按鈕** — 以自訂頻道（例如 `/p`）發送「地圖 ( X , Y )」並附最近傳送水晶，含可點擊的地圖連結
- **聊天訊息座標自動轉換** — 收到隊友傳的純文字座標時，自動轉成可點擊的地圖連結
- 完成勾選、一鍵路線最佳化（地圖分組＋最近鄰居法，與網頁版一致）、順序調整（房主可鎖定）、備註、負責玩家
- 選配整合 **Mappy**：把隊伍清單中尚未完成的寶物點「全部」同時畫在地圖上（未安裝時不受影響）
- 暱稱自動取自遊戲角色名稱 + 伺服器（例如 `玩家@利維坦`）

## 指令

- `/pth`：切換主視窗開關

## 安裝

1. 安裝 [XIVTCLauncher](https://github.com/ffxiv-tc-port/XIVTCLauncher)
2. 遊戲中輸入 `/xlsettings` 開啟 Dalamud 設定
3. 到「實驗性功能」的分頁
4. 找到「自定義插件倉庫」區塊，輸入：
   ```
   https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json
   ```
5. 按下「+」並儲存

遊戲中輸入 `/xlplugins`，到「已安裝」的區塊即可找到並啟用 **寶物地圖工具小幫手**。

## 台服版的修改

- 新增「前往」與「依路線前往下一個」（透過 Lifestream）
- 隊伍全部寶物點同時畫到 Mappy 地圖上
- 載入插件不再連線、自動重新加入上次的隊伍改成預設關；記住的隊伍已不存在時自動忘掉
- 斷線自動重連、連線狀態顯示與手動重連按鈕；登入憑證例行換發時立即重連
- 修正建立／加入／離開隊伍時弄壞成員與清單的問題
- 「優化路線」不能按時，滑鼠移上去會說明原因
- 用語改為台服官方譯名（寶物地圖、地圖名稱）

## 需要搭配的插件

- 選用：Lifestream（「前往」按鈕）、Mappy（在地圖上畫出全部寶物點）
